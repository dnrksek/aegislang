# AegisLang Roadmap

## v0.1 — Minimal Interpreter

Goal: build a small statically typed interpreted language.

Features:

- let / mut declarations
- Int / String / Bool
- arithmetic expressions
- comparison expressions
- equality expressions
- if / else
- print()
- assignment to mut variables
- static type checking
- interpreter
- CLI

## v0.2 — Functions

- function declarations
- function calls
- return statements
- local scopes
- parameter type checking
- return type checking

## v0.3 — Option / Result

- Option type
- Result type
- match
- ? operator

## v0.4 — Intent and Contracts

- intent metadata
- requires
- ensures
- runtime contract checking

## v0.5 — Effect System

- fs.read
- fs.write
- net.send
- net.receive
- process.exec
- env.read
- time.now
- random

## v1.0 — Security Automation Language

- JSON / CSV support
- log parsing
- basic network flow analysis
- rule engine
- security-oriented standard library
